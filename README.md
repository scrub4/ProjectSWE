# 🎬 SeatBite – Cinema Food Ordering System

## 📌 Project Description
SeatBite is a React-based front-end prototype that allows users to order food directly to their cinema seat. The system provides an interactive experience where users can select a movie, choose a cinema, pick their seat, and order snacks and drinks.

## 🚀 Features
- Movie selection  
- Cinema selection  
- Interactive seat booking  
- Food and drink ordering  
- Cart with total price calculation  
- Order tracking timeline  
- Responsive design  

## 🛠️ Technologies Used
- React (Vite)
- JavaScript (JSX)
- HTML & CSS

## ⚙️ Installation & Setup
1. Clone the repository
git clone <your-repo-link>
cd seatbite-app

2. Install dependencies
npm install

3. Run the project
npm run dev

4. Open in browser
http://localhost:5173

## 🧑‍💻 Usage
1. Select a movie  
2. Choose a cinema  
3. Pick your seat  
4. Add items to cart  
5. Place order  
6. Track delivery  

## 📌 Notes
- Front-end prototype only (no backend)
- Data is hardcoded
